Printing at home

  1. Open the printable PDF in Adobe Acrobat Reader (free) – browser PDF viewers sometimes change the scale.
  2. Choose File → Print and set the paper size to match the file (A4, US Letter, A5 or Half Letter).
  3. Set scaling to Actual size / 100 %. If you print an A4 file on Letter paper (or the other way round), choose Fit or Shrink oversized pages instead.
  4. For A5 / Half Letter on a standard printer, use Multiple pages per sheet → 2 or Booklet and cut in half.
  5. Print a single test page first to check margins and colours.
  6. For double-sided printing choose Flip on long edge.

Using it digitally (GoodNotes, Notability & more)

GoodNotes 5 / 6

  1. Download the digital PDF to your iPad (Files app) – on iPhone/iPad, tap the Etsy download link and choose Save to Files.
  2. Open GoodNotes → + New → Import and select the PDF. Choose Import as new document.
  3. Use the pen tool to write. Switch to Read-only mode (or tap with your finger while the pen is not selected) to tap links.

Notability

  1. Open Notability → Import → choose the PDF from Files.
  2. Tap links with your finger while in the scroll / select mode.

Other apps

Works in Noteshelf, Xodo, Samsung Notes, Adobe Acrobat and any PDF annotation app that supports internal links.
